A small app that runs on your own computer. Point it at a file you downloaded, or pick something already installed — it works out the rest. یک برنامهٔ کوچک که روی کامپیوتر خودتان اجرا می‌شود. فایلی را که دانلود کرده‌اید به آن بدهید، یا از نصب‌شده‌ها انتخاب کنید — بقیه‌اش را خودش انجام می‌دهد.

What is SLPM? SLPM چیست؟

SLPM opens in your web browser. You do not need to type commands or learn apt, snap and flatpak. It shows the programs on your computer with the same names and icons you see in your applications menu, and you install or remove them with a click. SLPM در مرورگر شما باز می‌شود. لازم نیست دستور بنویسید یا apt و snap و flatpak را یاد بگیرید. برنامه‌های روی کامپیوترتان را با همان نام و آیکونی که در منوی برنامه‌ها می‌بینید نشان می‌دهد، و با یک کلیک نصب یا حذفشان می‌کنید.

Install in three steps راه‌اندازی در چند مرحله

For setup, simply run the following commands in your terminal.برای راه‌اندازی، کافی است دستورات زیر را در ترمینال خود اجرا کنید.

$ sudo apt update && sudo apt install -y git python3 python3-venv  # Install Git, Python and venvنصب Git، پایتون و محیط مجازی
$ git clone https://github.com/parsasafaie/SLPM.git  # Clone the projectدریافت پروژه
$ cd SLPM  # Enter the project folderورود به پوشه پروژه
$ python3 -m venv .venv  # Create a virtual environmentساخت محیط مجازی
$ source .venv/bin/activate  # Activate itفعال‌سازی محیط مجازی
$ pip install -r requirements.txt  # Install dependenciesنصب وابستگی‌ها
$ python app.py  # Start SLPMاجرای SLPM

Then open http://127.0.0.1:8686 in your browser.سپس http://127.0.0.1:8686 را در مرورگر باز کنید.

What it does چه کارهایی می‌کند

Install a file you downloaded نصب فایل‌های دانلودشده

Drag the file in, or paste its path. SLPM recognises what it is and installs it the right way — no need to know which of the four formats you have. فایل را در کادر رها کنید یا مسیر آن را وارد کنید. SLPM نوع آن را تشخیص می‌دهد و به روش درست نصبش می‌کند — لازم نیست بدانید با کدام قالب سروکار دارید.

  • .deb
  • .AppImage
  • .flatpakref
  • .tar.gz / .zip

See everything you have installed همهٔ برنامه‌های نصب‌شده را یک‌جا ببینید

The same names and icons as your applications menu — not cryptic package names. Search the list, launch a program, read its details, or remove it. همان نام و آیکونی را می‌بینید که در منوی برنامه‌هاست؛ نه نام‌های فنی و نامفهوم بسته‌ها. فهرست را جست‌وجو کنید، برنامه‌ای را اجرا کنید، جزئیاتش را ببینید یا حذفش کنید.

Advanced mode, when you want more حالت پیشرفته، برای جزئیات بیشتر

One click reveals every installed package — libraries, drivers and system components included — with the details a package manager would show you. با یک کلیک همهٔ بسته‌های نصب‌شده، از کتابخانه‌ها و درایورها تا اجزای سیستمی، با همان جزئیاتی که یک مدیر بسته نشان می‌دهد در دسترس شما قرار می‌گیرند.

A warning before anything risky هشدار پیش از کارهای حساس

On Linux, removing the wrong thing can break the computer. SLPM tells you plainly when a package is part of the system, and asks you to confirm before it touches anything important. در لینوکس، حذف یک بستهٔ اشتباه ممکن است سیستم را از کار بیندازد. SLPM صریح می‌گوید کدام بسته جزء سیستم است و قبل از دست‌زدن به چیزهای مهم، از شما تأیید می‌گیرد.

What you need پیش‌نیازها

  • Linux with a desktop (developed on Ubuntu 26.04) لینوکس با محیط گرافیکی (توسعه و آزمایش روی Ubuntu)
  • Python 3.9 or newer پایتون ۳.۹ یا بالاتر
  • Your admin password, for installing and removing رمز عبور مدیر سیستم برای نصب و حذف

How it stays safe چطور از سیستم محافظت می‌کند

  • Runs only on your computer, not on the internet فقط روی کامپیوتر خودتان اجرا می‌شود و به اینترنت وابسته نیست
  • Your password is never stored anywhere رمز عبور شما هیچ‌وقت ذخیره نمی‌شود
  • Every command it runs is checked against a fixed list هر دستور پیش از اجرا با یک فهرست مجاز بررسی می‌شود
