# SLPM — مدیر بستهٔ سادهٔ لینوکس

[English](README.md)

SLPM یک برنامهٔ وب محلی برای نصب، مشاهده، اجرا و حذف نرم‌افزارهای لینوکس است. همه‌چیز روی همان کامپیوتری انجام می‌شود که برنامه در آن اجرا شده است و برای کارهای معمول نیازی به وارد کردن دستورهای مدیر بسته ندارید.

> SLPM به‌صورت محلی و روی `127.0.0.1:8686` اجرا می‌شود.

## امکانات

- دو حالت **ساده** و **پیشرفته** که با یک کلید کنار تب‌ها تغییر می‌کنند:
  - **حالت ساده** (حالت پیش‌فرض) در تب «برنامه‌های نصب‌شده» فقط برنامه‌هایی را نشان می‌دهد که SLPM تشخیص داده است کاربر آن‌ها را نصب کرده است. در تب «برنامه‌های استارتاپ» نیز فقط موردهای کاربری دیده می‌شوند. این فهرست می‌تواند شامل برنامه‌های نصب‌شده با `apt`/`dpkg`، `Snap`، `Flatpak` و میان‌برهای محلی باشد.
  - **حالت پیشرفته** در تب «برنامه‌های نصب‌شده» همهٔ بسته‌های نصب‌شدهٔ `dpkg`/`apt` را نشان می‌دهد؛ از جمله برنامه‌های از پیش نصب‌شده، اجزای سیستمی و بسته‌های حیاتی سیستم. تب «برنامه‌های استارتاپ» هم موردهای مربوط به بسته‌های سیستمی را نشان می‌دهد. این حالت، فهرستی یکپارچه از همهٔ منابع نرم‌افزاری نیست.
  - تب «نصب» در هر دو حالت یکسان است.
- SLPM برنامه‌هایی را که خودتان نصب کرده‌اید از موارد از پیش نصب‌شده تشخیص می‌دهد. این کار بر پایهٔ سابقهٔ خود ابزارهای بسته انجام می‌شود: نخستین تاریخ حضور هر بسته در گزارش `dpkg`، فهرست اولیهٔ `Snap` در `seed.yaml` و زودترین زمان ویرایش پوشه‌های commit در استقرار `Flatpak`. محل فایل‌های `.desktop` یا تاریخ تغییر فایل‌های `.list` مبنای این تشخیص نیستند، چون می‌توانند نتیجهٔ اشتباهی بدهند.
- تب «برنامه‌های استارتاپ» موردهای اجرای خودکار را نشان می‌دهد. در حالت ساده می‌توانید موردهای خودتان را اضافه کنید یا غیرفعال‌کنید؛ در حالت پیشرفته موردهای ارائه‌شده توسط بسته‌های سیستمی هم دیده می‌شوند. برای غیرفعال‌کردن مورد ارائه‌شده توسط یک بستهٔ سیستمی، SLPM فایل آن را تغییر نمی‌دهد و یک فایل کاربری هم‌نام می‌سازد.
- پشتیبانی از `.deb`، `AppImage`، فایل‌های `.flatpakref`، چند نوع آرشیو و فایل‌های `.run`/`.sh`؛ می‌توانید فایلی را که از قبل دارید نصب کنید یا آن را از یک لینک دانلود کنید. اسکریپت‌های `.run` و `.sh` خودکار اجرا نمی‌شوند و فقط می‌توانند به‌عنوان میان‌بر در منو ثبت شوند.
- هر دانلود به‌صورت یک کار در پس‌زمینه اجرا می‌شود؛ پیشرفت دانلود و کنترل‌های توقف موقت، ادامه و لغو دانلود را می‌بینید. پس از پایان دانلود، فایل به‌صورت خودکار نصب می‌شود، مگر اینکه هم‌زمان فایل دیگری را برای نصب انتخاب کرده باشید.
- اگر ابزارهای `apt`، `Flatpak` و `Snap` نصب باشند، SLPM آن‌ها را خودکار تشخیص می‌دهد.
- رابط فارسی و انگلیسی، همراه با تم روشن و تیره
- هشدار و تأیید پیش از عملیات حساس. حذف بستهٔ حیاتی سیستم می‌تواند باعث شود سیستم‌عامل بالا نیاید یا مدیریت بسته‌ها برای همیشه از کار بیفتد؛ این هشدار را جدی بگیرید. عملیات سطح سیستم برای گرفتن دسترسی مدیر از `pkexec` یا `sudo` استفاده می‌کنند و SLPM رمز شما را ذخیره نمی‌کند.

## پیش‌نیازها

- لینوکس با محیط دسکتاپ
- Python 3.9 یا جدیدتر
- `pkexec` یا `sudo` برای عملیات سطح سیستم

## نصب

دستورهای زیر را در ترمینال اجرا کنید:

```bash
sudo apt update && sudo apt install -y git python3 python3-venv  # Install Git, Python, and virtual-environment support
git clone https://github.com/parsasafaie/SLPM.git  # Clone the repository
cd SLPM  # Enter the project directory
python3 -m venv .venv  # Create a virtual environment
source .venv/bin/activate  # Activate the environment
pip install -r requirements.txt  # Install dependencies
python app.py  # Start the application
```

سپس <http://127.0.0.1:8686> را در مرورگر باز کنید. سرور توسعه را فقط روی localhost نگه دارید و آن را در دسترس اینترنت یا شبکه قرار ندهید.

## ساختار پروژه

```text
app.py              Flask application entry point
slpm/               Package and desktop-integration logic
                    (ownership.py decides which software the user installed
                    and which came with the system, and download.py fetches a
                    link in the background with pause, continue and stop)
templates/          HTML templates
static/             CSS and JavaScript assets
docs/               GitHub Pages website
requirements.txt    Python dependencies
```
