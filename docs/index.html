SLPM is a local app that runs on your own computer. Give it a local installer or a download link, and it recognises the file and installs it the right way. SLPM یک برنامهٔ محلی است که روی کامپیوتر خودتان اجرا می‌شود. فایلی را که می‌خواهید نصب کنید یا لینک دانلودش را به آن می‌دهید تا نوع فایل را تشخیص دهد و با روش مناسب نصبش کند.

What is SLPM? SLPM چیست؟

SLPM opens in your web browser and works on the same computer. You do not need to type apt, snap, or flatpak commands to install a file. In Simple Mode, Installed Apps uses the names and icons from your applications menu and shows the apps you installed; Advanced Mode opens the installed dpkg/apt package database. SLPM در مرورگر اجرا می‌شود و روی همان کامپیوتر کار می‌کند. برای نصب فایل لازم نیست خودتان دستورهای apt، snap یا flatpak را اجرا کنید. در حالت ساده، تب «برنامه‌های نصب‌شده» نام و نماد برنامه‌ها را همان‌طور که در منوی برنامه‌ها می‌بینید نشان می‌دهد؛ در این حالت فقط برنامه‌هایی دیده می‌شوند که خودتان نصب کرده‌اید. حالت پیشرفته فهرست بسته‌های نصب‌شدهٔ dpkg/apt را باز می‌کند.

Set up SLPM راه‌اندازی SLPM

Run these commands in a terminal to set up SLPM.برای راه‌اندازی SLPM، دستورهای زیر را در ترمینال اجرا کنید.

$ sudo apt update && sudo apt install -y git python3 python3-venv  # Install Git, Python and venv
$ git clone https://github.com/parsasafaie/SLPM.git  # Clone the project
$ cd SLPM  # Enter the project folder
$ python3 -m venv .venv  # Create a virtual environment
$ source .venv/bin/activate  # Activate it
$ pip install -r requirements.txt  # Install dependencies
$ python app.py  # Start SLPM

Then open http://127.0.0.1:8686 in your browser.سپس http://127.0.0.1:8686 را در مرورگر باز کنید.

What it does امکانات SLPM

Install a local file, or download and install one نصب فایل محلی یا دانلود و نصب خودکار

Choose a file already on this computer or paste a download link. SLPM recognises the supported file type and uses the appropriate installation or registration method. Downloads keep running in the background, with progress and pause, continue, and stop controls. A finished download is installed automatically unless another file is already selected. فایلی را که از قبل روی این کامپیوتر دارید انتخاب کنید یا لینک دانلود را وارد کنید. SLPM نوع فایل پشتیبانی‌شده را تشخیص می‌دهد و روش مناسب را برای نصب یا ثبت آن به کار می‌گیرد. دانلود در پس‌زمینه انجام می‌شود و پیشرفت آن را همراه با کنترل‌های توقف موقت، ادامه و لغو دانلود می‌بینید. پس از پایان دانلود، فایل خودکار نصب می‌شود؛ مگر اینکه هم‌زمان فایل دیگری برای نصب انتخاب کرده باشید.

  • .deb
  • .AppImage
  • .flatpakref
  • .snap
  • .tar.gz / .zip

The apps you installed, at a glance برنامه‌هایی که خودتان نصب کرده‌اید

Simple Mode shows only programs that the package managers' records identify as installed after the operating system, along with relevant local entries. It uses the same names and icons as your applications menu. Search the list, launch a program, read its details, or remove it. حالت ساده فقط برنامه‌هایی را نشان می‌دهد که در سابقهٔ ابزارهای بسته، نصبشان پس از نصب سیستم‌عامل ثبت شده است، به‌همراه میان‌برهای محلی. نام و نماد هر برنامه از منوی برنامه‌ها گرفته می‌شود. در فهرست جست‌وجو کنید، برنامه را اجرا کنید، جزئیاتش را ببینید یا حذفش کنید.

Startup Apps, under your control برنامه‌های استارتاپ، زیر نظر شما

The Startup Apps tab lists the entries a desktop session can start: those supplied by packages and the desktop environment, plus entries you added. Simple Mode shows your own entries. Advanced Mode also shows packaged entries, each with its enabled state. Turning off a packaged entry creates a user override instead of changing a system file. تب «برنامه‌های استارتاپ» موردهایی را نشان می‌دهد که نشست دسکتاپ می‌تواند اجرا کند: موردهای ارائه‌شده توسط بسته‌ها و محیط دسکتاپ، به‌همراه موردهایی که خودتان اضافه کرده‌اید. حالت ساده فقط موردهای کاربری را نشان می‌دهد. حالت پیشرفته موردهای ارائه‌شده توسط بسته‌های سیستمی و وضعیت فعال یا غیرفعال هرکدام را هم نشان می‌دهد. برای غیرفعال‌کردن مورد بستهٔ سیستمی، SLPM به‌جای تغییر فایل سیستمی یک فایل کاربری هم‌نام می‌سازد.

Advanced Mode for apt/dpkg packages حالت پیشرفته برای بسته‌های apt/dpkg

In Advanced Mode, Installed Apps switches to the installed dpkg/apt package database. It can include pre-installed applications, libraries, drivers, system components, and essential packages. Startup Apps also includes packaged startup entries. This is not a unified list of every software source, and the Install and Updates tabs are the same in both modes. در حالت پیشرفته، تب «برنامه‌های نصب‌شده» به فهرست بسته‌های نصب‌شدهٔ dpkg/apt تغییر می‌کند. در این فهرست ممکن است برنامه‌های از پیش نصب‌شده، کتابخانه‌ها، درایورها، اجزای سیستمی و بسته‌های حیاتی سیستم باشند. تب «برنامه‌های استارتاپ» نیز موردهای ارائه‌شده توسط بسته‌های سیستمی را نشان می‌دهد. این حالت فهرستی یکپارچه از همهٔ منابع نرم‌افزاری نیست و تب‌های «نصب» و «به‌روزرسانی‌ها» در هر دو حالت یکسان هستند.

See what can be updated, install by name به‌روزرسانی‌ها را ببینید و با نام نصب کنید

The Updates tab lists what each package manager has available: expand a manager's list, update one item or the whole manager at once, and refresh the apt package lists. A snap that is still running is marked, and SLPM asks you to close it before updating it; a failed run shows the full error, not just one line. On the Apps page you can also install by name: search the apt repositories as you type, or enter the exact name of a snap or a Flatpak app. تب «به‌روزرسانی‌ها» فهرست می‌کند هر مدیر بسته چه چیزی برای به‌روزرسانی دارد: فهرست یک مدیر را باز کنید، یک مورد را جداگانه یا همهٔ موارد آن را یک‌جا به‌روزرسانی کنید و فهرست بسته‌های apt را تازه کنید. snapی که هنوز درحال‌اجراست مشخص می‌شود و SLPM پیش از به‌روزرسانی آن از شما می‌خواهد آن را ببندید؛ اگر اجرا شکست بخورد، خطای کامل نشان داده می‌شود، نه فقط یک خط. در صفحهٔ برنامه‌ها می‌توانید با نام هم نصب کنید: مخازن apt را حین تایپ جست‌وجو کنید یا نام دقیق یک snap یا یک برنامهٔ Flatpak را وارد کنید.

A warning before anything risky هشدار پیش از عملیات پرخطر

On Linux, removing the wrong package can stop programs from working or prevent the computer from starting. SLPM marks system components and essential packages, explains the risk, and asks you to confirm before removal. There is no undo, and SLPM does not create backups. در لینوکس، حذف بستهٔ اشتباه می‌تواند برنامه‌ها را از کار بیندازد یا مانع روشن‌شدن کامپیوتر شود. SLPM جزء سیستمی یا بستهٔ حیاتی سیستم را مشخص می‌کند، خطر را توضیح می‌دهد و پیش از حذف از شما تأیید می‌گیرد. SLPM نمی‌تواند تغییرات را بازگرداند و نسخهٔ پشتیبان نمی‌سازد.

What you need پیش‌نیازها

  • A Linux desktop environment (developed on Ubuntu 26.04) لینوکس با محیط دسکتاپ (توسعه روی Ubuntu 26.04)
  • Python 3.9 or newer Python 3.9 یا جدیدتر
  • Administrator access when a system operation needs it دسترسی مدیر برای عملیات سطح سیستم

How it stays safe ایمنی SLPM

  • Runs locally by default; do not expose the server to the network به‌صورت پیش‌فرض محلی اجرا می‌شود؛ سرور را در دسترس شبکه قرار ندهید
  • Your administrator password is never stored by SLPM SLPM رمز مدیر شما را ذخیره نمی‌کند
  • Package commands use argument arrays rather than shell strings دستورهای مدیریت بسته با آرایهٔ آرگومان اجرا می‌شوند، نه با رشتهٔ shell
