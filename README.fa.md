# SLPM — مدیر سادهٔ بسته‌های لینوکس

[English](README.md)

یک برنامهٔ وب محلی و ساده برای نصب، مشاهده، اجرای و حذف نرم‌افزارهای لینوکس، بدون نیاز به استفادهٔ مستقیم از دستورهای مدیر بسته.

> SLPM به‌صورت محلی و روی `127.0.0.1:8686` اجرا می‌شود.

## امکانات

- حالت ساده و پیشرفته برای مشاهدهٔ برنامه‌ها و بسته‌های نصب‌شده
- تب «برنامه‌های هنگام ورود» برای دیدن برنامه‌هایی که خودکار اجرا می‌شوند، با افزودن و حذف یک‌کلیکی
- پشتیبانی از `.deb`، AppImage، Flatpak، آرشیوها و فایل‌های نصب
- شناسایی خودکار ابزارهای `apt`، Flatpak و Snap
- رابط انگلیسی و فارسی با تم روشن و تیره
- تأیید و بررسی ایمنی برای عملیات مربوط به بسته‌ها

## پیش‌نیازها

- لینوکس با محیط گرافیکی
- Python نسخهٔ ۳٫۹ یا بالاتر
- `pkexec` یا `sudo` برای عملیات مربوط به بسته‌ها

## نصب

دستورات زیر را در ترمینال اجرا کنید:

```bash
sudo apt update && sudo apt install -y git python3 python3-venv  # نصب Git، پایتون و پشتیبانی محیط مجازی
git clone https://github.com/parsasafaie/SLPM.git  # دریافت Repository
cd SLPM  # ورود به پوشهٔ پروژه
python3 -m venv .venv  # ساخت محیط مجازی
source .venv/bin/activate  # فعال‌سازی محیط مجازی
pip install -r requirements.txt  # نصب وابستگی‌ها
python app.py  # اجرای برنامه
```

سپس <http://127.0.0.1:8686> را در مرورگر باز کنید. سرور توسعه را فقط روی localhost نگه دارید و آن را در معرض اینترنت قرار ندهید.

## تست

```bash
source .venv/bin/activate
python selftest.py
```

## ساختار پروژه

```text
app.py              نقطهٔ ورود برنامهٔ Flask
slpm/               منطق بسته‌ها و اتصال به میزکار
                    (autostart.py مدیریت موارد هنگام ورود)
templates/          قالب‌های HTML
static/             فایل‌های CSS و JavaScript
docs/               وب‌سایت GitHub Pages
requirements.txt    وابستگی‌های Python
```
